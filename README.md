# ECLIPSE: Reino de las Cenizas

RPG 2D de acción y fantasía oscura en pixel art. Sprint 0: base técnica jugable.

## Requisitos
- Node.js 20 o superior
- npm

## Ejecutar
```bash
npm install
npm run dev
```
Abre la dirección local que indique Vite (normalmente `http://localhost:5173`). Para compilar: `npm run build`.

## Controles
- PC: WASD o flechas para moverse; Enter/Espacio para comenzar.
- Móvil: joystick virtual en la mitad izquierda de la pantalla.

## Estado actual
- Menú inicial y escena de prueba.
- Movimiento en 8 direcciones, límites del mundo y guardado local de posición.
- Guerrero, Arquero y Hechicero están definidos como clases iniciales del diseño; la selección de clase y sus sistemas de combate se implementarán en el siguiente sprint.
- Los gráficos actuales son placeholders procedurales para validar el juego antes de importar arte final.

## Arte externo
Se priorizarán recursos CC0 o con licencia compatible. Revisar y registrar la licencia y atribución de cada archivo antes de distribuir el juego. Fuentes: https://opengameart.org/content/cc0-resources y https://opengameart.org/content/cc0-2d-rpg.
